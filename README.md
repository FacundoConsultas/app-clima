#  App de Clima Pro - Consulta en Tiempo Real

### 🔗 [Ver Demo en Vivo](https://facundoconsultas.github.io/app-clima/)

¡Bienvenido a mi buscador de clima! Este proyecto es una aplicación web moderna que se conecta a la API de **OpenWeatherMap** para obtener datos meteorológicos exactos de cualquier ciudad del mundo.

##  Características Principales
- **Datos en tiempo real:** Obtiene temperatura, humedad y descripción del cielo.
- **UX Optimizada:** Permite buscar presionando la tecla **Enter**.
- **Interfaz Dinámica:** El color de fondo cambia según la temperatura (Frío ❄️ / Templado 🌤️ / Cálido 🔥).
- **Diseño Glassmorphism:** Interfaz moderna con efectos de transparencia y desenfoque.

##  Tecnologías Usadas
- **HTML5** & **CSS3** (Variables de CSS y Flexbox).
- **JavaScript (ES6+)**: Consumo de APIs con `fetch` y `async/await`.
- **OpenWeather API**: Fuente de datos meteorológicos.
